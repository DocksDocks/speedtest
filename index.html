Evidence Categories

Primary Evidence Map

Avahi / mDNS

Local discovery for printers, casting, and .local names. Stop it only when you do not need local discovery.

MTU 1500

Standard Ethernet packet size. Lower it only when path MTU tests show fragmentation or blackhole problems.

BSSID Pin

A BSSID is one physical access point radio. Pinning can help a fixed desk, but should be re-tested when you move.

DNS Choice

DNS affects lookup time, not raw bandwidth. It can help clients start connections faster.

Network Manager

NetworkManager is the default laptop Wi-Fi manager. The iwd backend is worth testing only with rollback ready.
